# Assembly SDK (frozen contract)

`assembly` is preloaded in the persistent sim session. A call returns a
JSON-safe value or raises a structured `AssemblyError`; `assembly.safe_call("method", key=value)`
returns `{"ok": ..}` instead of raising. Signatures below are exact: arguments
after `*` are keyword-only. Do not edit this file or restate a signature elsewhere.

Mesh frame is `link`: an OBJ's vertices are in its own link-visual frame and are
drawn at `T_world_link(q) @ T_link_visual`. `set_joint_world_frame` moves a
joint frame (and the child mesh with it); `set_link_visual_pose` moves only the
mesh; `set_joint_positions` moves children on top of that.

| Method | Contract |
|---|---|
| `import_parts(INPUT_DIR, *, replace=True)` | Import every OBJ (vertices preserved exactly, textures never decoded); returns `[{handle, label, vertices}]` with handles like `part:part_0.obj`. |
| `inspect_parts()` | Handle, label, vertex count, local and world AABB of every part. |
| `create_link(name, parts, *, visual_xyz=(0,0,0), visual_rpy=(0,0,0))` | Register one or more part handles as a rigid link. |
| `create_joint(name, joint_type, parent, child, origin_xyz, *, origin_rpy=(0,0,0), axis="Z", limits=None)` | Add a FIXED / REVOLUTE / CONTINUOUS / PRISMATIC joint; rejects cycles, multiple parents, zero axes, invalid limits. |
| `set_joint_world_frame(name, world_origin, world_axis=None)` | Set a joint from its q=0 world pivot and axis; partial trees are fine. |
| `set_link_visual_pose(name, world_xyz, world_rpy=(0,0,0))` | Place a link's mesh at a q=0 world pose without moving any link frame. |
| `set_joint_positions({name: q})` / `reset_joints()` | Move joints within limits and run FK / return to q=0. |
| `audit(*, require_complete_tree=True, verify_source_vertices=True)` | Structural audit: `ok`, counts, issues. |
| `render_preview(path, *, azimuth_deg=45, elevation_deg=25, resolution=512, views=2)` | PNG of the current pose; `views=2` adds the opposite side as `<stem>_az<NNN>.png`. Azimuth 0 = camera on −Y, counter-clockwise from above. |
| `render_joint_sweep(joint, output_dir, *, steps=4, azimuth_deg=45, elevation_deg=25, resolution=512, views=2)` | `steps` legal poses of one joint as `<joint>_<index>_<pct>pct.png` (plus `_az<NNN>` views), one fixed camera; restores q=0. `output_dir` must be inside `OUTPUT_DIR`. |
| `export_urdf(OUTPUT_DIR, *, history=False)` | Reset q=0, audit, write `furniture.urdf` plus its mesh/material assets atomically. An accepted alternative to filling `template.urdf` by hand. |
